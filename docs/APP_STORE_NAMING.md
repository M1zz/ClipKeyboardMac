# App Store 이름 규칙 — 아이폰 앱 · 맥 앱 공통

두 앱은 **번들 ID 가 달라서 App Store Connect 에서 별도의 앱 레코드**다.

```
iOS    com.Ysoup.TokenMemo         (id1543660502)
macOS  com.ysoup.TokenMemo-tap
```

앱 이름은 스토어 전체에서 고유해야 하므로 두 레코드에 똑같은 이름을 넣을 수 없다.
그렇다고 플랫폼 이름으로 구분하면 **리젝된다**(가이드라인 2.3.7 Accurate Metadata).
`for Mac`, `iPhone판`, `Mac Edition` 같은 말은 쓰지 않는다.

## 규칙

```
[브랜드] : [그 앱이 하는 일]
```

- 브랜드는 두 앱·네 언어에서 **항상 같다**. 한 제품이라는 인상이 여기서 나온다.
- 구분은 **뒤쪽 서술어**로만 한다. 플랫폼·기기·등급(Pro, Plus) 단어를 쓰지 않는다.
- 이름 필드 30자 이내. 키워드 나열 금지(2.3.7).
- 부제(Subtitle)도 30자, **별도 필드**다. 이름 고유성은 부제로 못 푼다 — 이름 필드 안에서 해결한다.
- 부제에도 같은 2.3.7 이 적용된다. 플랫폼 이름·키워드 나열 금지, 앱 이름을 되풀이하지 않는다.
- 이름은 **무엇인가**, 부제는 **어디서 어떻게 쓰는가**를 적는다. 둘이 같은 말을 하면 한 칸을 버리는 것이다.

## ⚠️ 브랜드가 로케일마다 갈려 있다

| | 스토어 이름의 브랜드 | 기기에 뜨는 이름 | 맞나 |
| --- | --- | --- | --- |
| 한국어 | 클립키보드 | 클립키보드 | ○ |
| English | Clip Keyboard (두 단어) | ClipKeyboard (한 단어) | △ |
| 简体中文 | ClipKeyboard | 剪贴键盘 | ✗ |
| 繁體中文 | ClipKeyboard | 剪貼鍵盤 | ✗ |

중국어가 어긋난 경위: 1순위 `剪貼鍵盤` 이 **이미 쓰이는 이름이라 거절**돼서
간체·번체 모두 라틴 브랜드로 갔다. 그런데 앱 안 표시 이름은 한자 그대로다.

가이드라인 2.3.8 은 스토어 이름과 기기에 뜨는 이름이 서로 알아볼 수 있어야 한다고 본다.
`ClipKeyboard - 快捷短语一键输入` 과 `剪贴键盘` 은 겹치는 글자가 없다. 둘 중 하나를 고를 것.

**가 안 — 기기 이름을 라틴으로 되돌린다.** `zh-Han*.lproj/InfoPlist.strings` 의
`CFBundleDisplayName` 을 `ClipKeyboard` 로. 스토어 이름은 그대로 두면 되고 심사가 다시
필요 없다. 다만 앱 안 본문에 넣은 한자 이름(아이폰 45곳·맥 16곳)도 함께 되돌려야 말이 맞는다.

**나 안 — 스토어 이름을 한자로 바꾼다.** 5.0.5 는 아직 제출 전이라 지금은 고칠 수 있다.
간체는 `剪贴键盘` 이 거절된 적이 없으니 될 가능성이 있고, 번체만 다른 한자 브랜드를
찾으면 된다(`快捷短語`, `短語鍵盤` 등). 앱 안 문구는 손대지 않아도 된다.

⚠️ 어느 쪽이든 **간체와 번체가 서로 다른 브랜드를 쓰는 것만은 피한다.**

## 기기에 뜨는 이름 (`CFBundleDisplayName`)

이쪽은 고유성 제약이 없다. **두 앱이 같아야 한다** — 두 기기를 함께 쓰는 사람에게
같은 앱으로 보여야 하기 때문이다.

| 언어 | 값 | 어디에 |
|---|---|---|
| (기본값) | ClipKeyboard | 맥은 `INFOPLIST_KEY_CFBundleDisplayName`, 아이폰은 `Info.plist` |
| 한국어 | 클립키보드 | `ko.lproj/InfoPlist.strings` |
| English | ClipKeyboard | `en.lproj/InfoPlist.strings` |
| 简体中文 | 剪贴键盘 | `zh-Hans.lproj/InfoPlist.strings` |
| 繁體中文 | 剪貼鍵盤 | `zh-Hant.lproj/InfoPlist.strings` |

⚠️ 맥 앱의 `.tap` 은 Xcode 타깃 이름일 뿐 사용자에게 보이지 않는다.
   중국어 이름을 따로 만들 이유가 없어 아이폰과 같은 값을 쓴다.

⚠️ 앱 안 본문에서 한자 이름 뒤에 공백을 넣지 않는다.
   `退出 剪贴键盘` (✗) → `退出剪贴键盘` (○).
   영문 이름 기준으로 쓴 문구를 그대로 번역하면 이 공백이 남는다.
